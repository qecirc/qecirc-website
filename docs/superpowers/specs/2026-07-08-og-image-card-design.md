# Static og:image social card — design

**Date:** 2026-07-08
**Status:** Approved (visual mockup approved by maintainer)

## Problem

Pages shared on Slack/X/LinkedIn render text-only: `Layout.astro` emits
`og:title/description/type/url/site_name` and `twitter:card: summary`, but no
image tag of either kind.

## Decision

One **static** branded card used site-wide (per maintainer choice). Per-code
generated cards are a possible future addition — they would pass a per-page
`og:image` override through `Layout`, requiring no rework of this change.

## Design

### Asset: `public/og-card.png` (1200×630)

Approved visual: white background; two horizontal circuit wires spanning the
card; the favicon's filled "Q" gate on the left; the wordmark **QECirc**
inside an outlined gate box on the same wires; gray tagline
"A community-driven library for quantum error correction circuits"; small
monospace `qecirc.com` beneath.

Generated by `scripts/icons/generate.mjs` (extended with a second SVG +
target), following that script's existing conventions: sharp renders `<text>`
with host fonts, so the PNG is generated on macOS and committed; the script
is re-run only when the design changes. Render at 2× density and downscale
to 1200×630 for crisp text.

`apple-touch-icon.png` is regenerated by the same script run but must not be
committed with byte-level diffs unless intentionally changed — restore it via
git if only the og-card was targeted.

### `Layout.astro` head (site-wide, all pages inherit)

```html
<meta property="og:image" content={`${siteUrl}/og-card.png`} />  <!-- absolute URL required by crawlers -->
<meta property="og:image:width" content="1200" />
<meta property="og:image:height" content="630" />
<meta property="og:image:alt" content="QECirc — a community-driven library for quantum error correction circuits" />
<meta name="twitter:card" content="summary_large_image" />  <!-- was: summary -->
<meta name="twitter:image" content={`${siteUrl}/og-card.png`} />
```

## Testing & verification

- `curl` a rendered page and assert all six tags with the absolute image URL.
- Confirm `/og-card.png` serves 200 with `image/png` and is 1200×630.
- `npm run lint`, `format:check`, `build`, `scripts/smoke.sh`.
- Post-deploy sanity check with a card validator (e.g. opengraph.xyz).
