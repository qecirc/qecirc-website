# ILP flag-based state-prep import (arXiv:2607.22498)

Imports the 13 fault-tolerant state-preparation circuits of Criger, Hankin,
Burau & Perry, _"Automated Flag-based Fault-Tolerant State Preparation using
Integer Linear Programming"_ ([arXiv:2607.22498](https://arxiv.org/abs/2607.22498),
Quantinuum). The circuits use the circuit gauge operator formalism to build
flag/verification gadgets by integer linear programming; every circuit here
includes those flag qubits and their measurements (post-selected).

## Dataset

The paper releases no machine-readable circuits and no code repository, so the
STIM bodies in [`circuits/`](circuits/) were recovered from the paper sources
(arXiv v1) and are vendored here:

- **10 circuits from tikz figures.** The paper's `*_prep.tikz` files were
  generated by [qpic](https://github.com/qpic/qpic), which preserves its full
  input line-by-line in `% Line N:` comments — wire declarations with initial
  states, CNOTs, measurement bases, ancilla lifetimes. Sorting by source line
  number recovers the exact gate sequence; this is lossless.
- **3 circuits from figure PDFs** ([[24,4,5]], [[42,10,6]], [[23,1,7]]):
  these figures ship as standalone PDFs, so the circuits were reconstructed
  from the PDF vector content (wires, control dots, target circles, ket and
  measurement-basis glyphs, including the dashed "cut" that splits each
  figure into two stitched blocks). The extractor was verified to reproduce
  three known tikz circuits **exactly** from PDFs produced the same way.

Every extracted circuit was validated by stabilizer simulation (flags
post-selected on trivial outcomes) against the paper's own tableaux appendix:
[[16,4,4]] low-weight (12/12 generators at +1), [[24,10,4]] both preps
(14/14), [[24,4,5]] (20/20), [[42,10,6]] (32/32). The [[23,1,7]] circuit has
no tableau in the paper and was validated intrinsically: its data-qubit
stabilizer group has the exact [23,12,7] Golay / Golay-dual weight
enumerators, and a binary [23,12,7] code is unique up to permutation.

STIM convention: data qubits `0..n-1` in the paper's numbering, flags `n..`;
reset-free (`|0…0⟩` implied), `|+⟩` inits as a leading `H` layer.

## Anchors and fits

[`anchors.py`](anchors.py) holds the paper's stabilizer generators, extracted
mechanically from the appendix of `HighDistanceStatePrep.tex` (the extraction
splits generator lists on line breaks as well as commas, so it is robust to
the tex's formatting). The paper's labeling **is** each circuit's labeling
(verified: all generators at +1 on the simulated prep state), so anchor fits
are the identity. The [[16,1,4]] anchor is not in the paper; it is the
textbook d=4 rotated surface code in row-major order, which matches the
circuit exactly (row-space equality checked for Hx, containment for Hz).

Fit strategy per code:

- **paper anchor, new code**: `24-10-4` (|0⟩ and |+⟩ — the |+⟩ prep dedups
  onto the code its twin creates), `24-4-5`, `42-10-6` (two-block group
  algebra codes, also listed at qecdb.org), `16-4-4-low-weight`.
- **self-dual derivation, new code**: `16-4-4` — the [[16,4,4]] color code of
  Prabhu & Reichardt ([arXiv:2112.03785](https://arxiv.org/abs/2112.03785));
  the paper calls it the twisted color code.
- **constructed anchor, new code**: `rotated-surface-code-d-4` (fills the gap
  between the stored d=3 and d=5 rotated surface codes).
- **existing code, auto-dedup**: `23-1-7` — the canonical-hash ladder
  resolves the Golay permutation itself (the direct `find_code_permutation`
  search does _not_ terminate here; the M₂₃-sized automorphism group defeats
  its column-invariant refinement).
- **existing codes, precomputed σ** ([`sigma_precomputed.json`](sigma_precomputed.json),
  convention `σ[new] = old` = `σ[stored] = paper`; every σ is re-verified by
  the pipeline's row-space check at import): `carbon-code`, `16-2-4`,
  `16-6-4` (σ = identity — the paper uses the stored labeling), `17-1-5`
  (auto-dedup reports uncertain, exactly as in the flag-at-origin import),
  `20-2-6`. The color-code σ come from `find_code_permutation`; the carbon
  code is k=2 and not self-dual, so a |0⟩ circuit only determines
  ⟨Hz, logical-Z⟩ on the Z side and its σ was found by a one-off
  X-side-pruned backtracking search with the Z-containment checked at the
  leaves.

## Decisions

- **Two distinct [[16,4,4]] codes.** The twisted color code takes the plain
  `16-4-4` slug; the paper's weight-six code (obtained by projecting two
  logical qubits of the [[16,6,4]] Reed-Muller code into a Bell pair) is
  **provably a different code** — X-span weight enumerators
  `{0:1, 4:4, 8:54, 12:4, 16:1}` vs `{0:1, 6:16, 8:30, 10:16, 16:1}` — so it
  is imported `assume_new` as `16-4-4-low-weight`.
- **No tool entry.** The paper's ILP implementation is not publicly released,
  so circuits carry only `source` (and the paper record makes them searchable
  by title/author/arXiv id). If Quantinuum releases the tool, add it then.
- **Fault-detection order lives in the notes.** The captions claim detection
  of all fault sets up to size 2 (d=4 codes) or 3 (d≥5 codes); that claim is
  the paper's, recorded per circuit, not re-verified here and not a tag.
- **`connectivity: all-to-all`** matching the flag-at-origin import: the
  circuits target Quantinuum's trapped-ion hardware (the paper runs the
  [[24,10,4]] gadget on System Model H2).
- **Extraction toolchain is not vendored.** The qpic/PDF extraction scripts
  live outside the repo (the circuits are treated as given data, validated as
  above); this directory holds the import logic only.
